# traitar_download

**Tags:** <a href="/developers/tags/phenotype" class="badge badge--primary badge--tag">phenotype</a> <a href="/developers/tags/traits" class="badge badge--primary badge--tag">traits</a> <a href="/developers/tags/pfam" class="badge badge--primary badge--tag">pfam</a> <a href="/developers/tags/database" class="badge badge--primary badge--tag">database</a> <a href="/developers/tags/download" class="badge badge--primary badge--tag">download</a> <a href="/developers/tags/run-scope" class="badge badge--primary badge--tag">run-scope</a> 

Download the Pfam database required by Traitar.

Fetches the pre-compiled Pfam database required by [Traitar](https://github.com/nick-youngblut/traitar3/)
for microbial phenotype prediction. The database contains Pfam HMM models used for
protein family annotation during trait prediction.

:::note[Internet & Storage Required]
This process requires an active internet connection and significant disk space
to store the Pfam database files (~1.2GB).
:::

## Outputs

```
record (
    db: Path,
    logs: Set<Path?>
)
```

| Field | Type | Description |
|-------|------|-------------|
| `db` | `Path` | The Pfam-A HMM file for Traitar |
| `logs` | `Set<Path?>` | Optional program specific log files |

## Parameters

### Traitar Download Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `--traitar_db` | string | - | Path a Traitar database (should contain the Pfam-A.hmm file) |
| `--download_traitar` | boolean | `false` | Download the Pfam database to the path given by --traitar_db |
