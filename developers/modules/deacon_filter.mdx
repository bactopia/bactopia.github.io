# deacon_filter

**Tags:** <a href="/developers/tags/host" class="badge badge--primary badge--tag">host</a> <a href="/developers/tags/contamination" class="badge badge--primary badge--tag">contamination</a> <a href="/developers/tags/decontamination" class="badge badge--primary badge--tag">decontamination</a> <a href="/developers/tags/depletion" class="badge badge--primary badge--tag">depletion</a> <a href="/developers/tags/filtering" class="badge badge--primary badge--tag">filtering</a> <a href="/developers/tags/minimizer" class="badge badge--primary badge--tag">minimizer</a> <a href="/developers/tags/reads" class="badge badge--primary badge--tag">reads</a> <a href="/developers/tags/deacon" class="badge badge--primary badge--tag">deacon</a> <a href="/developers/tags/sample-scope" class="badge badge--primary badge--tag">sample-scope</a> 

Filter host reads from sequencing data using minimizer-based comparison.

Uses [deacon](https://github.com/bede/deacon) to identify and remove host reads from
FASTQ files using SIMD-accelerated minimizer comparison against a pre-built or custom
reference index. Supports paired-end, single-end, and long reads.

:::note[Database Required]
Requires a deacon minimizer index. Use the deacon/fetch module to download a pre-built
index (e.g., panhuman-1) or deacon/index to build one from a reference FASTA.
:::

## Parameters

### Deacon Filter Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `--deacon_abs_threshold` | integer | `2` | Minimum absolute number of minimizer hits for a match |
| `--deacon_db` | string |  | Path to a pre-existing deacon index (.idx) for host read filtering |
| `--deacon_deplete` | boolean | `true` | Discard matching sequences instead of keeping them |
| `--deacon_opts` | string |  | Additional deacon filter options not covered by other parameters |
| `--deacon_prefix_length` | integer | `0` | Search only the first N nucleotides per sequence (0 for all) |
| `--deacon_rel_threshold` | number | `0.01` | Minimum relative proportion (0.0-1.0) of minimizer hits for a match |
